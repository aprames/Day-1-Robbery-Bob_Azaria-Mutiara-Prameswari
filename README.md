Deskripsi Singkat Repository
Repository merupakan tempat penyimpanan dan dokumentasi selama mengikuti kegiatan workshop berjudul "Building with AI, Managing Change with GitHub".

Tujuan atau Kegunaan Repository
Kegunaan utama repository ini adalah untuk mengelola, menyimpan, dan mempublikasikan seluruh dokumentasi kegiatan, catatan materi, serta hasil praktik secara daring menggunakan GitHub.

Rangkuman Materi Workshop
Sesi workshop dibawakan oleh Nugi Farhan, Senior Product Designer, materi berfokus pada dua topik utama yaitu pemanfaatan AI dan manajemen perubahan kode. 
Materi pertama membahas Prompt Engineering, yaitu cara merancang instruksi atau masukan kepada AI agar menghasilkan jawaban yang tepat dan layak digunakan. Prompt yang baik sangat bergantung pada konteks dan idealnya disusun dengan struktur Role, Task, Context, serta Format. Penerapan prompt yang tepat dapat meningkatkan performa AI, mengurangi bias, dan memberi kita kontrol yang lebih baik terhadap hasil akhirnya.
Materi kedua mengupas perbedaan mendasar antara Git dan GitHub. 
Git adalah version control system yang diciptakan oleh Linus Torvalds pada tahun 2005 untuk melacak siapa, kapan, dan apa saja yang diubah dalam suatu file secara lokal. 
Sementara itu, GitHub adalah platform berbasis web yang dipakai untuk menyimpan repository Git tersebut secara online agar mempermudah kolaborasi. Alur kerja Git dimulai dari mengedit file di Working Directory, memindahkannya ke Staging Area sebagai persiapan, lalu menyimpannya secara permanen di dalam Git Directory atau Repository. 

Poin-Poin Penting atau Pengetahuan Baru
Menyusun prompt AI yang terstruktur menggunakan format Role, Task, Context, dan Format untuk mendapat hasil yang akurat.
Membedakan fungsi dasar: Git untuk version control di komputer lokal, sedangkan GitHub untuk hosting repository secara online.
Menggunakan perintah wajib Git di terminal, meliputi git init (membuat repo), git add (memasukkan file ke staging area), dan git commit (menyimpan perubahan).
Mengamankan koneksi otentikasi antara komputer lokal dan GitHub melalui pembuatan SSH Key.

Hari pertama workshop ini seru dan insightful. Awalnya lumayan bingung membedakan Git dan GitHub, tapi penjelasannya to the point jadi langsung paham kalau Git itu alat lokalnya dan GitHub itu tempat hosting-nya.
Materi soal Prompt Engineering juga ngasih pencerahan karena selama ini kadang asal ketik saat pakai AI.
